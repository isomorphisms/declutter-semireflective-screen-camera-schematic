# Registration continuation — 10 November 2026

**New work is a geometric trial, not a reconstructed circuit.**

The original twelve 1152 × 1536 JPEG photographs were recovered and checked
against the recorded source-manifest digests. Registration used previously
marked circuit landmarks, not the stationary glass border or reflections.

coordinates. Coefficients are represented in millionths in the Idriç consumer;
there are no floating-point values at its runtime geometry boundary.

The tolerances and source correspondences are *visual estimates*, not
millimeter-calibrated control points, and a held-out **landmark** is not a
held-out electrical circuit trace. For each accepted pair the selected model
retains its similarity restriction (uniform scale + rotation + translation);
a three-point general affine fit would overfit the sparse control overlap.

## Rendering contract

1. Produce each P6 RGB photograph through a format decoder, retaining the raw
   JPEG for comparison. The format decoder supplies bytes, not any cleanup.
2. Apply the existing Idriç local-mean contrast operation separately for
   readability; retain the unenhanced version in parallel.
3. For a registered pair, read its exact six-line plan in
   [registration/paired](../registration/paired). Map the earlier photograph
   into the later photograph's coordinate space using **integer, fixed-point**
   similarity inversion. Nearest-neighbour sampling selects one observed pixel;
   there is no bilinear blend or generated conductor.
4. When source coverage overlaps, select the earlier observation above the
   documented seam row and the later observation below it. If the preferred
   observation is outside its admitted crop, fall back to the other observation.
   Pixels for which neither input contains an observation stay white.
5. Assemble the two power-column pairs side-by-side, separated by a visibly
   different gutter. Similarly, assemble the unregistered left control
   segments in their recorded order and place the right control top segment
   above its landmark-supported lower pair. Keep visible gutters at
   **unaccepted** joins.

The fixed-point source deliberately does **not** synthesize stroke geometry to
hide residual mismatch. It also does not mark successful electrical continuity
at the registered seam: <10px fit error is still multiple printed line widths.

## Evidence and limits

Local reference-image trial dimensions:

- control: 2328 × 3633 pixels;
- power: 2431 × 1912 pixels.

The raw and enhanced versions were generated as separate local **reference
trials**, using a transient image analysis adapter to solve least-squares fits
and inspect registered images. These trial PNG/PNM files are not asserted to
have been generated by the new Idriç registration executable.

The earlier Idriç raster reader, local-contrast enhancer, and axis-aligned
assembler have historical host-execution receipts. **New**
`Registration.idric` and `RegistrationTests.idric` have not been compiled
or executed in the current container: the pinned Idriç + Chez toolchain was
not available here. The next acceptance must build at the pinned compiler,
run the arithmetic and image fixtures, compare its pixel maps with the
reference trial, and reject any mismatch. An independent review must inspect
whether the source landmark labels themselves are identical features.

The reference trial and the full-resolution images still exhibit glare,
dust, and captured navigation graphics. Missing/obscured text remains missing.
In particular, no result from this continuation is a verified manufacturing
service schematic.

All raw photos and the photographer's reflection stay **out of the public
repository**. Output digests and deterministic plan parameters may be kept
here without exposing those private images.

## Independent, image-feature cross-check

A separate read-only SIFT analysis using contrast-limited feature detection
found 16 candidate matches within 12 pixels of the **control 1716 → 1717**
landmark solution (median 1.66 pixels) and 12 for **power 1720 → 1723**
(median 3.50 pixels). These are inspection-only diagnostics: the matching
method and its possible false matches are not part of the Idriç renderer.
No such feature corroboration was obtained for **1721 → 1722** (only two
SIFT ratio-test matches, neither near the fitted transform), so its visual
join remains **PROVISIONAL** despite four manually recorded features.

New fixed-point reference trials use **grey** for pixels covered by neither
photo and select exactly one RGB source sample per covered pixel. They use
the published integer coefficients rather than a floating-point warp. The
test outputs remain **reference execution only**, not executed Idriç output.
Their SHA-256 digests are in `evidence/registered-trials.sha256.tsv`.
