# Inspectable schematic cleanup in Idriç

Dependently typed Idriç experiments for processing photographs of electrical schematics displayed on reflective HMI screens.

The implementation is developed on a separate branch so its source, execution evidence, and image limitations can be reviewed together.

## Reference documents

[Retech / Pollard document archive](references/retech-pollard/README.md): twelve
unaltered uploaded photographs of electrical drawings, installation drawings,
program descriptions and handwritten terminal notes, with source hashes,
transcriptions and qualified interpretations.
